# KEIRIN 公開・仮想投票台帳

**実資金の投票はありません。** 2026-11-08に仮想投票の実績0件から開始。過去の的中結果を事前投票として記録しません。

## 保存ファイル

- journal.jsonl: 事前に確定した仮想車券と結果を追記するSHA256ハッシュ連鎖台帳。GitHub履歴と併用するが完全な不正防止ではありません。
- summary.json: 戦略・賭式別の的中率・回収率。未決着と全額返還は分母に入れません。
- verified_models.json: 独立した実データ検証が終わったモデルの許可一覧。現状は空なので、優位性を主張する edge は記録できません。
- inbox/*.json: v0.6の予想と公式確定結果の受信箱。
- ledger.py: GitHub Actionsの実際の実行時刻で、締切前判定・重複排除・採点を行うコード。

## 使い方

1. KEIRIN.JPなどから利用条件に従って合法的に取得した、開催前の出走表と2車複/3連単の完全な締切前オッズを準備する。収集元・時刻を必ず記録する。
2. v0.6の paper_bet.py place で生成した PAPER_BET 出力を、次のJSON封筒で inbox/ に提出する。

~~~json
{"event_type":"bet","proposal":{"status":"PAPER_BET","...":"v0.6 の実出力で置換"}}
~~~

3. GitHub Actionsがpush時と毎時に同期。実行時点で締切まで10〜180分・オッズ取得から10分以内でなければ受理しない。GitHubが受理する前に締切が過ぎたデータは、たとえ過去に予想をしていても前向き実績にしない。
4. レース確定後に公式の払戻表と確定時刻を次の形式で inbox/ に保存する。

~~~json
{"event_type":"settlement","result":{"race_id":"実在する記録済みレースID","status":"final","confirmed_at_jst":"YYYY-MM-DDTHH:MM:SS+09:00","source_url":"https://keirin.jp/...","payouts":{"2shafuku":{"1-2":330},"3rentan":{"1-2-3":2600}}}}
~~~

※この数字はダミー。実際のソースを確認した結果で置換すること。同着による複数当たりを反映する。取消・特殊返還は確認してから対応する。

## 記録区分

- baseline/2shafuku: 2車複市場1番人気を仮想購入する比較戦略。利益が出るとは主張しません。実際の1番人気かどうかは提出した候補と全オッズの独立照合が別途必要です。
- edge/2shafuku: 独立検証済みAIが予測した2車複。
- edge/3rentan: v0.6の事前モデルが順序確率と期待値を満たす場合に限り切替。
- edgeの条件は補正後期待回収倍率1.30以上。これは目標であり利益保証ではありません。
- 台帳は「事前に提案された券の記録・採点」を行うものであり、モデル推論、元の全組合せオッズの監査、外部サイトからの自動収集は含まれません。

コマンド例：python paper_trading/ledger.py stats --root paper_trading

**現状：過去・前向きとも実際の仮想投票決着は0件。的中率・回収率は算出不可です。**
