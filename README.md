# Keirin — 3連単オッズ収集・検証

研究用プロジェクト。買い目は原則として**人気上位100点**を対象に、確定着順と突合する。オッズの予測力と回収率を区別し、事後の確定オッズを締切前の予測と混同しない。

- **Top100完了レース：0**。未取得の51〜100位を推測値で補完しない。

## データ仕様
`race_id` = `YYYYMMDD_aomori_RR`。確定結果の `winning_final_odds` は100円あたり払戻金 / 100。結果一覧に基づく既取得データの再掲であり、今回のGitHubアップロードはサイト再取得ではない。

収集時はソースURL、取得時刻、オッズが確定か締切前か、車立て数、欠車・返還状況を記録する。Top100の購入候補として使えるか判定する場合、Top100に的中が含まれないレースも必ず保持する。全組み合わせの事前確率にTop100だけを正規化した値を用いない。

## 実装方針
1. KEIRIN.JPとKドリームスの公開データ・利用条件を確認
2. 低頻度で日別・レース別に取得、429/403/認証画面では停止
3. 人気順位100位まで重複なしで保存、買い目・払戻と突合
4. 収集ログと失敗原因も残し、完全性検査を合格したものだけ推論に使う
5. 時系列で学習・検証・試験に分割。ROIは購入時点のオッズで別評価

競輪市場の情報は統計的推定であり、収益を保証しない。

## 修正：日付ごとの**全開催会場**を対象にする（2026-11-01）
これまでの「別日付・別会場を1組ずつ追加」は不完全な網羅方法だった。1日には複数の競輪場で同時開催があるため、**日付→公式開催一覧に載った全競輪場→全レース**を列挙し、`(date, venue_slug, race_number)` で管理する。開催なしは行を作らず、開催あり・未取得は明示的に残す。過去の単一開催日まとめは部分的な報告として保持する。

- 2026-10-30 **8会場 / 75掲載レース**：岐阜、青森、弥彦、別府、宇都宮、西武園、松戸、名古屋
