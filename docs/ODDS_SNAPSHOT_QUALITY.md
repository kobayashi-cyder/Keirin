|---|---:|---:|---|
| 2車複 | 21 | 21 | 構造上の全件 |
| 2車単 | 42 | 42 | 構造上の全件 |

この `complete=True` は**買い目集合と件数の形式的な完全性**だけを意味します。各買い目の数字がサイトの数字と独立照合できたことを意味しません。

ブラウザで確認したKドリームスの同レースには、3連単の**1着車番を選択して見る6×6のオッズ表**が存在します。既存のスクレイパーは人気順トップ50を読み取る設計で、表の残りの160点を読み取っていません。**欠けた160点を推測で埋めないこと**。追加通信なしで取得済みHTMLの表を確実に解析するには、DOMの車番・見出し・行/列の対応が正しいかテストする必要があります。

## 2026-11-08追加：3連単の全買い目を同一HTMLから復元する試験処理

`tools/odds_3rentan_matrix.py` を追加し、`tools/browser_odds_watch.py` に接続しました。

現在のページには、各「1着車番」ごとに2着の列・3着の行を並べたオッズ表があり、7車立てなら7個の6×6表に210組のオッズが表示される構造です。新プログラムは**すでに読み込んだHTMLを解析するだけ**で、表の追加取得やAPIへの別アクセスは行いません。

- 7車は210組、8車は336組、9車は504組の**すべて**が表から得られなければ採用しません。
- 人気順トップ50の組番・倍率と、表から復元した該当組番の倍率をすべて突き合わせます。少しでも違えば復元を破棄します。
- **数字を推測で埋めず**、照合不成立時には既存の人気順トップ50の記録だけを保持します。
- 成功時は `three_rentan_matrix_verification=crosschecked_full_matrix`、`3rentan.count=210`、`3rentan.complete=true` になります。
- 失敗時は `3RENTAN_MATRIX_NOT_VERIFIED: ...` がコンソールに表示されます。
- この「照合済み」は**同じページの2表同士の内部整合**を意味し、第三者による独立照合や更新頻度保証ではありません。

現時点で**実際のページHTML上での実行検証は未了**です。HTMLに複数の表示用表や異なるタグ構造がある場合は機械的に失敗して正常です。その場合、収集対象を増やす前に解析を修正してください。

また、既に保存した `7520261108010001.jsonl` にはHTMLが含まれないため、**古いJSONLだけから不足160点は復元できません**。有効な締切前レースを新たに1回取得して確認します。サイトの利用条件やアクセス制限を引き続き尊重します。

テスト：

```cmd
py -3 -m unittest discover -s tests -p "test_odds_3rentan_matrix.py" -v
```

## Windowsのオッズ品質チェック

GitHub最新版をWindowsで解凍し、ルートで：

```cmd
py -3 tools\audit_odds_snapshot.py --input local_data\odds_snapshots\7520261108010001.jsonl --output local_data\audit_matsuyama_01.json
```

出力の主な項目：

- `status=STRUCTURE_CHECK_PASSED_NOT_SOURCE_VERIFIED`：賭式別買い目・価格の基本的な整合性だけが合格。サイトと照合済みではない。
- `markets.3rentan.missing=160`：人気順トップ50のため160買い目が不足。
- `page_update_times`：**サイトが画面に表示したオッズ更新時刻**（保存されている場合）。
- `odds_observed_at`：ブラウザがページのHTMLを読み込んだ時刻。**サイトのオッズ更新時刻とは別物**。
- `source_freshness`：表示時刻が欠けていたり、取得した時刻より10分超古いときは警告。10秒間隔でページを読み込むことは、サイトが10秒ごとに更新している証拠ではない。
- `current_usability=HISTORICAL_DO_NOT_TREAT_AS_LIVE`：投票締切を過ぎた記録。実際の予測や当日買い目として使わない。

ローカルオッズの解析は第三者コンテンツの再利用・公表権限を付与しません。ライセンス未確認、モデル未検証の段階では `alert_allowed=false` / `bet_allowed=false` のままです。

テスト：

```cmd
py -3 -m unittest discover -s tests -p "test_audit_odds_snapshot.py" -v
```
