## 契約前に確認する必須項目

1. 全国全レースの共通レースID、日程、車番、選手ID、ライン、競走得点、脚質、近走成績。
2. 全7賭式の買い目別オッズ（3連単・3連複・2車単・2車複・2枠単・2枠複・ワイド）。非発売の区別。
3. オッズの観測時刻、配信遅延、更新頻度、ワイド幅オッズと確定オッズの区別。
4. 締切・発走・欠場・中止・失格・同着・返還情報、結果・100円払戻の履歴。
5. レース前のオッズ・出走表を過去に遡って取得できるか。結果だけではモデル検証に不足。
6. API仕様書、認証、料金、帯域・レート制限、配信契約の条件。
7. データのローカル保存、統計学習、個人Discord通知、公開GitHubでの再配信が許可される範囲。

## 導入の条件

- 提供元から仕様書・利用条件・サンプルを取得したら、専用APIアダプターを作る。未知のエンドポイントとJSON形式を推測で書かない。
- 秘密鍵は環境変数またはGitHub Secrets。チャット、公開コード、レースCSVに記載しない。
- 保管先は Windows の local_data/。第三者のデータを再配布する許諾がなければGitHubに同期しない。
- 正規化・締切前検査: tools/intake_pre_race.py。着順モデルの研究評価: tools/train_baseline.py。
- モデルの時系列検証、確率校正、前向き仮想投票が済むまで verified_models.json を更新しない。
