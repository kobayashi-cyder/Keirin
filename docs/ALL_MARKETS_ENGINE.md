# 全7賭式の確率投影エンジン（試験運用・購入不可）

`paper_trading/all_markets.py` は、**レース前に生成された1〜3着の同時確率**（または同時シミュレーションした選手別ゴール時刻）を、7賭式の的中確率へ変換します。GitHubの既存仮想台帳や通知とは**未接続**です。

## 動作確認（Windows / Python 3.11以上）

リポジトリのルートで次を実行します。サードパーティーライブラリ、OpenAI APIキー、Discordの設定は不要です。

```cmd
py -3 paper_trading\all_markets.py --demo
py -3 -m unittest discover -s tests -p "test_all_markets.py" -v
```

`--demo` は架空の強さとオッズを使う数学検証で、実競輪の予測ではありません。`projection_probability_sums` のワイドが約3、それ以外が約1なら、配分に整合性があります。ワイドは1回の決着で原則3組が的中するので合計3です。

## 入力仕様

個別レースの仮想検証には、**外部で用意したモデル出力と、取得権限のあるオッズ**をJSONとして与えます。モデル自体の学習・確率校正はこのPRの対象外です。下は架空の例です。7車分のゴール時刻を**同じレースについて一組ずつ**入力します。選手ごとの独立シミュレーションを前提にはしません。

```json
{
  "race_id": "SYNTHETIC_7CAR",
  "cars": [1, 2, 3, 4, 5, 6, 7],
  "probability_input": {
    "type": "joint_finish_time_samples",
    "samples": [
      [180.01, 180.02, 180.03, 180.04, 180.05, 180.06, 180.07],
      [180.02, 180.01, 180.03, 180.04, 180.05, 180.06, 180.07]
    ]
  },
  "offered_odds": {
    "3rentan": {"1-2-3": 10.0},
    "2shatan": {"1-2": 5.0},
    "3renpuku": {"1-2-3": 3.2},
    "2shafuku": {"1-2": 2.4},
    "2wakutan": {"1-2": 4.5},
    "2wakufuku": {"1-2": 2.3},
    "wide": {"1-2": {"min": 1.8, "max": 2.2}}
  },
  "odds_source_url": "https://example.org/fictional",
  "odds_observed_at": "2026-11-08T12:00:00+09:00",
  "deadline_at": "2026-11-08T12:30:00+09:00"
}
```

```cmd
py -3 paper_trading\all_markets.py --input example.json --output research.json
```

もう1つの入力方式は `"probability_input": {"type":"top3_probabilities", "values":{"1-2-3":0.01, "...":0.002}}` です。**全着順について合計1の確率質量**が必要です。未知の確率を勝手にゼロ埋めしないでください。入っていない組番はゼロと扱うので、推定モデルで出せない場合は分析しません。

### 賭式コードと的中条件

| コード | 賭式 | 投影方法 |
|---|---|---|
| `3rentan` | 3連単 | 順序どおりの上位3車 |
| `3renpuku` | 3連複 | 上位3車の順不同 |
| `2shatan` | 2車単 | 1・2着の順序 |
| `2shafuku` | 2車複 | 1・2着の順不同 |
| `2wakutan` | 2枠単 | 1・2着の枠順、同枠あり |
| `2wakufuku` | 2枠複 | 上位2枠の順不同、同枠あり |
| `wide` | ワイド | 上位3車から2車の順不同 |

7/8/9車の枠割りに対応し、9車立ては4-5が4枠、6-7が5枠、8-9が6枠です。7車立てで枠賭式が発売されないレースもあるので、`offered_odds` には**実際に発売される賭式だけ**を記載します。欠けた賭式のオッズを作らないでください。

ワイドのようにオッズが幅の場合、`min` を使います。デフォルトの安全側係数0.75を用いて `推定的中確率 × オッズ下限 × 0.75 >= 1.30` の条件を表示します。この係数は仮定であり、統計的信頼区間でもオッズ下落の保証でもありません。別途データで検証する必要があります。

## 安全側の制約

- `SHADOW_ONLY_UNVALIDATED`：条件に一致しても**Discord通知や仮想購入に回しません**。`alert_allowed=false` 固定。
- 同着、失格、棄権、返還、ワイド同着時の例外は対象外。どのレースでも単純な上位3車順列だけで正しく扱えるとは限りません。
- 保存済みの確定払戻・事後オッズを、事前に利用可能な予測の代わりにしません。上がりタイムはゴール到達時刻とは別の指標です。
- 強さから算出するデモのPlackett–Luce分布は**学習済みモデルではありません**。実用に向けては事前特徴量の整備、校正、時系列ホールドアウト、前向き仮想投票の検証が必要です。
- データの自動取得や第三者サイトの複製は実装していません。取得・保存の利用許諾は別途確認してください。
- 市場の発売有無、締切、オッズ鮮度を記録しますが、それだけで投票許可やモデル検証済みを意味しません。
