# 取得元調査メモ（2026-11-01）

## 確認済みの取得環境
- GitHub Actions上から `https://keirin.jp/pc/search` と `https://keirin.kdreams.jp/` にはDNS解決・HTTP 200で到達できた。トップページへの到達は個々の過去レースの取得成功を意味しない。
- 楽天Kドリームスには日別開催一覧・開催別結果・人気順オッズページが存在する。
- `https://keirin.kdreams.jp/info/sitepolicy/` では掲載情報の無断転載・無断コピー等が禁止されている。第三者の公開GitHubへ無制限に複製する許可は未確認。GitHub Issue #1で整理中。

## 再利用許諾が未確認の候補
- [Kenseimk/keirin-data](https://github.com/Kenseimk/keirin-data)：2024年からの月別CSVを含み、出走・着順・払戻を扱う。ただしGitHub APIのリポジトリメタデータではライセンスが指定されていない（2026-11-01確認）。公開されていることを再配布許可と誤認しない。3連単Top100全オッズの収録は未確認。
- [superme1on/keirin-ai-auto](https://github.com/superme1on/keirin-ai-auto)：別プロジェクトの予測・検証コード。履歴CSV URLはユーザー設定が必要。実データの供給源と同一視しない。

## 今後の実行条件
1. 開催日・競輪場・レース番号の索引は、公開掲載内容と突き合わせて出典URLを保持する。
2. 結果・オッズは出典、取得日時、許可された利用範囲を記録する。第三者CSVの大量取り込み・公開は再利用条件が確認できるまで実行しない。
3. 完全収録は `data/coverage_summary.json` の `top100_races` にのみ計上し、単なる的中組番の確定倍率を個別Top100オッズ100点と混同しない。
4. 出典で「中止」「欠車」「同着」が生じた場合は通常レースと区別し、欠損として架空補完しない。

このファイルは取得・再利用の判断メモであり、許諾証明ではない。
